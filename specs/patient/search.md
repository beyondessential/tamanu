# Patient search

Searching for patients from the All patients listing.

## Alternative identification number

- [ ] The advanced fields of the All patients search include an "Alternative identification number" field
- [ ] A value entered in the field matches patients whose birth certificate, driving licence, passport or insurance policy number starts with that value
- [ ] Matching ignores letter case
- [ ] The field does not search the patient's NHN, which has its own search field
- [ ] The field combines with the other search fields, so results match every field filled in
