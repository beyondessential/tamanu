# Discontinued medications in pharmacy

Discontinuation gates which prescriptions can be sent to pharmacy, not what pharmacy can dispense. A prescription can be discontinued at any time, including after a pharmacy order already exists, and that later discontinuation does not change the order.

## Ordering

- [ ] A discontinued prescription cannot be added to a new pharmacy order.
- [ ] Attempting to send a discontinued prescription to pharmacy reports that it has been discontinued.

## Dispensing

- [ ] A medication request whose prescription has since been discontinued remains in the pharmacy queue.
- [ ] Such a request stays selectable in the dispense workflow and dispenses like any other request.
- [ ] The dispensed record of such a fill is the same as for any other fill.
