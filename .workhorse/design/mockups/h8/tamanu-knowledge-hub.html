Birth certificate number on vaccination certificates

Vaccination certificates can show a patient's recorded birth certificate number. Off by default, enabled under Vaccinations settings.

Server configuration moves to the admin panel

A large amount of server configuration is now editable in the admin panel rather than in config files.

Automatic invoicing of encounter and bed fees

Encounter, bed and inpatient fees are invoiced automatically, so facilities no longer add routine charges by hand.
