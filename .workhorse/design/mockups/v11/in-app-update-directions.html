In-app update: two directions

How Tamanu mobile updates itself when central rejects an out-of-date app (#V11). Both directions are drawn on the app's shipped home, sign-in and Sync screens. Anything tagged Proposed changes the earlier draft.

A. Updating Tamanu screen

Staff keep working while the update downloads, and a home screen alert shows where it's up to. It only installs on the Updating Tamanu screen, reached by logging out or tapping Install now, so Android never closes a half-filled form.

B. Quiet update

The update downloads with nothing on screen and installs when staff leave Tamanu or lock the screen with no form open. The only UI is the one-off permission, Android's first-update prompt, and alerts when the update is stuck. Still untested: whether Android allows the install while Tamanu is in the background.
