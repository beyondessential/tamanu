Release notes

What changed in each version of Tamanu, with upgrade notes and recommended testing. Sourced from the release notes in GitHub.

v2.63 Released 3 September 2026

A small release of enhancements and fixes. Vaccination certificates can show a patient's birth certificate number, patient lists gain sortable columns, and deployments that report to DHIS2 can mark datasets complete when they are posted.

System enhancements
  • DHIS2 dataset completion — For deployments that report to DHIS2, each configured dataset is marked complete when it is posted. The dataset is set against a report through the report admin panel.
Tweaks and bug fixes
  • Patient lists — Additional columns, including Area and Location, can now be sorted, making it easier to organise a working patient list.
  • Vaccination certificates — A new ‘Display birth certificate number’ flag shows the patient's recorded number on the certificate. Off by default.
  • Medications — All medication preset labels load, and the administration schedule section is collapsed by default.
  • Imaging — ‘X-ray (Portable)’ is added as an imaging type.
v2.62 Released 17 August 2026

Configuration moves into the admin panel

A modest release. Its main change is administrative: a large amount of server configuration moves into the admin panel. Clinically, the ‘Send to pharmacy’ workflow extends to discharge and prescribing, and lab requests gain out-of-range result flags.

Major features and changes

Configuration managed in the admin panel

Configuration that previously lived in files on each server is now database-backed settings, editable in the admin panel with validation and per-facility overrides. Existing values migrate automatically during the upgrade.

  • Editable without server access — Mail, scheduled tasks, integrations, localisation, reporting and rate limiting are managed in the admin panel.
  • Applied without a restart — A saved setting takes effect on the next read, and the few that need a restart are marked.
  • Integration credentials encrypted — Secrets use one deployment-wide key, generated by central and distributed to facilities over sync.

‘Send to pharmacy’ from discharge and prescribing

Medications can now be sent to pharmacy at the two points where prescribing happens. At discharge the patient's encounter medications are ticked to send by default, with stock and previous requests visible while deciding.

  • At discharge — A ‘Send to pharmacy’ column on the ‘Discharge’ modal, ticked for encounter medications.
  • When prescribing — A ‘Send to pharmacy’ option on the ‘New prescription’ modal, off by default.
Critical upgrade notes
  • Configuration moved into settings — Existing configuration migrates automatically. Review it in the admin panel afterwards. Configuration files are still read as a fallback, so do not remove them.
  • Sync lookup rebuild — The central upgrade performs a full sync lookup rebuild as its final step. Allow extra time for large databases.
v2.61 Released 10 August 2026

Automatic encounter, bed and inpatient fees

Automatic invoicing of encounter, bed and inpatient fees, so facilities no longer add routine charges by hand, plus a substantial set of medication improvements.

Major features and changes

Automatic encounter, bed and inpatient fees

Routine charges are now added to invoices automatically as care happens. An outpatient or emergency fee is applied when a visit starts, and admitted patients accrue a bed fee for each night.
