Sending medications to pharmacy

How to send prescribed medications to pharmacy at prescribing and at discharge.

Medications can be sent to pharmacy at the two points where prescribing happens: when writing a new prescription, and when discharging a patient. Sending a medication creates a pharmacy order so it can be dispensed and tracked.

Before you start

The pharmacy fields appear only where the pharmacy order setting is enabled for your facility. If you do not see them, ask your administrator.

Sending when prescribing

When you write a new prescription, you can send it to pharmacy in the same step.

  1. Open the patient's encounter and select New prescription.
  2. Complete the medication details as usual.
  3. Turn on Send to pharmacy. It is off by default.
  4. Enter a Dispensing quantity, then save the prescription.

Sending at discharge

At discharge, the patient's encounter medications are ticked to send by default, so routine discharge medications go to pharmacy without extra steps.

  • The Discharge modal shows a Send to pharmacy column, ticked for encounter medications and unticked for other ongoing medications.
  • Stock on hand, when a request was last sent, and whether it is still active or already dispensed are shown while you decide.
  • Dispensing quantity must be filled in for each medication being sent.

Tracking a sent medication

Once sent, a medication appears in the pharmacy's queue. The prescription record shows its status as it moves from ordered to dispensed.

Release notes

What changed in each version of Tamanu, with upgrade notes and recommended testing. Sourced from the release notes in GitHub.

v2.63Released 3 September 2026

A small release of enhancements and fixes. Vaccination certificates can show a patient's birth certificate number, patient lists gain sortable columns, and deployments that report to DHIS2 can mark datasets complete when they are posted.

System enhancements
  • DHIS2 dataset completion — Each configured dataset is marked complete when it is posted, set against a report through the report admin panel.
Tweaks and bug fixes
  • Patient lists — Additional columns, including Area and Location, can now be sorted.
  • Vaccination certificates — A new ‘Display birth certificate number’ flag shows the patient's recorded number. Off by default.
  • Imaging — ‘X-ray (Portable)’ is added as an imaging type.
v2.62Released 17 August 2026

Configuration moves into the admin panel

A modest release. A large amount of server configuration moves into the admin panel, the ‘Send to pharmacy’ workflow extends to discharge and prescribing, and lab requests gain out-of-range result flags.

Major features and changes

Configuration managed in the admin panel

Configuration that previously lived in files on each server is now database-backed settings, editable in the admin panel with validation and per-facility overrides.

  • Editable without server access — Mail, scheduled tasks, integrations, localisation and reporting are managed in the admin panel.
  • Applied without a restart — A saved setting takes effect on the next read.

‘Send to pharmacy’ from discharge and prescribing

Medications can now be sent to pharmacy at the two points where prescribing happens. At discharge the patient's encounter medications are ticked to send by default.

Critical upgrade notes
  • Configuration moved into settings — Existing configuration migrates automatically. Configuration files are still read as a fallback, so do not remove them.
  • Sync lookup rebuild — The central upgrade performs a full sync lookup rebuild as its final step. Allow extra time for large databases.
v2.61Released 10 August 2026

Automatic encounter, bed and inpatient fees

Automatic invoicing of encounter, bed and inpatient fees, so facilities no longer add routine charges by hand, plus a substantial set of medication improvements.

Major features and changes

Automatic encounter, bed and inpatient fees

Routine charges are now added to invoices automatically as care happens. An outpatient or emergency fee is applied when a visit starts, and admitted patients accrue a bed fee for each night.
