You print a lab request's results from the request, starting from the **Labs** tab of the patient's
encounter. What you can print depends on the request's status: final results once it is verified or
published, an interim report before then, and a rejection report if the laboratory rejected the
sample.

# Before you start

Printing results is switched on per site, and needs permission to view lab results. If you believe you
should be able to print results, contact your system administrator.

# Steps

1. Select the request. The lab request opens.
2. Print the report for the request's status:
   - **Verified** or **Published**: select **Print results**
   - **Reception pending**, **Results pending**, **Interim results** or **To be verified**: select the
     three dots beside **Print request**, then **Print interim report**. The report shows that the
     results aren't final
   - **Rejected**: select **Rejection report**

   A request whose sample isn't collected, or that has been invalidated, has no results to print.

   **[Screenshot: the Lab results printout preview]**

3. Select **Print**.
