If a lab request was made in error, you can cancel it, starting from the **Labs** tab of the patient's
encounter. A published request can't be cancelled.

# Steps

1. Select the request. The lab request opens.
2. Select the three dots beside **Print request**, then **Cancel request**. The **Cancel lab request**
   window opens.

   **[Screenshot: the Cancel lab request window]**

3. Choose the reason for cancelling. Some reasons permanently delete the request, and the window
   tells you when you have chosen one.
4. Select **Confirm**. The request's status shows **Cancelled**.
