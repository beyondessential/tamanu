When the laboratory has tested a sample, you enter the results on the lab request. Start from the
**Labs** tab of the patient's encounter, or from the **Labs** listings (see
[17.8 Find lab requests](8-find-lab-requests.md)).

# Before you start

You need permission to enter results, and a published request's results can't be changed. If you
believe you should be able to enter results you can't, contact your system administrator.

# Steps

1. Select the request. The lab request opens, with its tests listed in a table.
2. Select **Enter results**. The **Enter results** window opens, listing each test on the request.

   **[Screenshot: the Enter results window for a liver function panel]**

3. For each test with a result, enter the **Result**. Where they apply, also fill in:
   - **Secondary result**, where the test records one
   - **Method**
   - **Verification**
   - **Completed**, the date the test was completed
4. Enter any notes on the results in **Results interpretation**.
5. Select **Confirm**. The results appear in the request's table. The status stays as it was, so
   change it when your laboratory's process requires (see
   [17.4 Update a lab request](4-update-a-lab-request.md)).
