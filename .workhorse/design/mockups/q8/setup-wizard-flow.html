Facility setup wizard flow

A new facility server shows this wizard before anything else. It is used by the person installing the server, who enters the central server address, a central administrator's login, and the facilities the server serves.

Today, once the wizard finishes, nobody can log in to the facility until its first sync has downloaded all of the facility's data, which can take hours. Login is refused as if the user had no access, and nothing tells anyone the server is still being set up.

This card keeps the wizard as it is and changes what happens after it: the server downloads just enough to let people log in, and anyone who logs in before the first sync finishes sees a setting-up screen until it does. Those screens are seen by facility staff, not only by the installer.
