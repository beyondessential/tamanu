## Your task: Security audit

Review the implementation for security concerns: the OWASP Top 10 and any other issues you find. Use your judgement about what matters for this code. Find the card's base and diff against it as `.agents/docs/bases-and-dependencies.md` says, and reference specific files and lines.

### Recording findings

Record the findings as `.agents/docs/card-issues.md` "Recording an audit's findings" says, with the summary grouped by severity.
