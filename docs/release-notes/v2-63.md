Released 03-09-2026

Tamanu v2.63 is a modest release. Its main change lets a clinician save a part-finished discharge and come back to it. Alongside this, vaccination certificates can show a patient's birth certificate number, patient lists gain sortable columns, and the facility server now protects against duplicate records when a client retries a request.

---

# 🌟 Major Features and Changes

## Tamanu Desktop

### _Save and Resume a Discharge_

Discharging a patient is a long form: discharge date, discharging clinician, disposition, the medications the patient leaves with, and the treatment plan and follow-up notes. A clinician interrupted part way through can now save what they have entered and return to it later, instead of losing the work or holding the form open until they can finish.

**Key features**

- **'Save & exit'** - The 'Discharge' form offers 'Save & exit' alongside finalising the discharge. Saving stores the form as it stands and closes it without discharging the patient, so the encounter stays open and the clinician stays on it.
- **Private to each clinician** - Each clinician has their own draft on an encounter and sees only their own, so one person saving cannot disturb another's part-finished work. An encounter that the clinician has a draft on shows an indicator that a draft is waiting.
- **Restored on return** - Reopening the form restores the discharge details and each medication's quantity, repeats, and whether it is being sent to pharmacy. The treatment plan and follow-up notes come back as the clinician left them, with any discharge planning notes written since the draft was saved appended.
- **Cleared when done** - Finalising the discharge clears every draft on that encounter. Closing a form with unsaved changes asks whether to save and exit, discard, or return to the form.

# 🔧 System Enhancements

- **Birth certificate number on vaccination certificates** - A new 'Display birth certificate number' flag under the 'Vaccinations' settings shows the patient's recorded birth certificate number in the patient details section of the vaccination certificate. It is off by default, and the field is left empty where no number has been recorded.
- **Sortable patient list columns** - Columns on the patient listings can now be sorted, making it quicker to find patients in long lists.
- **Portable X-ray imaging type** - A new 'X-ray (Portable)' imaging request type is available once its reference data is loaded.
- **DHIS2 dataset completion** - For deployments that report to DHIS2, report data is pushed as datasets and each configured dataset is marked complete when it is posted. The DHIS2 dataset is set against a report through the report admin panel.
- **Safe retries on the facility server** - A mutating request the facility web client retries after a dropped connection is now executed at most once, so a retry can no longer create a duplicate record. This works quietly in the background and needs no configuration.

# 🐛 Tweaks and Bug Fixes

## Desktop

- **Medications** - The medication administration record no longer errors for a drug that has no dosing unit, and the dose unit is omitted from its tooltip in that case. Medication labels print from a dedicated frame, all preset labels load rather than only the first 25, and the 'Medication administration schedule' section is collapsed by default in the medication form.
- **Invoicing** - Adding an invoice item no longer causes a crash, and historical invoice products are excluded from automatic invoice item lookups.
- **AI patient summary** - Fixed placeholder text appearing at the start of a generated summary.
- **Surveys and charts** - Large numeric answers display without being rounded, and a rare crash when the survey 'Complete' button is clicked is fixed.
- **Patients and dashboard** - The encounter refreshes after a death is recorded, and the current day's appointment and booking panes fill in even when tasking is turned off.

## Mobile

- The vitals 'Add' tab submits correctly after a prior submission, a resync migration race condition is fixed, and query performance is improved through additional database indexes and periodic refreshing of query statistics. The Android build is updated to support devices with 16 KB memory pages.

## System

- **Reports** - Soft-deleted survey responses are excluded from the generic survey export.

# ⚠️ Critical Upgrade Notes

### Optional

**_Vaccination certificate birth certificate number_**

- The birth certificate number is off by default. Enable 'Display birth certificate number' under the 'Vaccinations' settings if you want it on the certificate.
- The number is drawn from patient details, so it appears only for patients who have one recorded.

**_Portable X-ray_**

- The 'X-ray (Portable)' request type appears once the corresponding imaging type reference data is loaded. Add it if this type is needed at your facility.
