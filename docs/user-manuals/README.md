# Tamanu user guides

Step-by-step guides to using Tamanu, written for the staff who use it day to day.

Guides describe how Tamanu works. How your own site has been set up is separate, so some screens and
options look different depending on your site's configuration. If you cannot do something you
believe you should be able to, contact your system administrator.
