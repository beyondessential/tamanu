# Mobile

Guides to using Tamanu on a mobile device.

## Modules

- [1. Access](access/index.md): Signing in, choosing a facility, and signing out.
- [2. Patients](patients/index.md): Finding patients, registering them, and viewing their details.
- [3. Vitals](vitals/index.md): Recording and reviewing a patient's observations.
- [4. Diagnosis and treatment](diagnosis-and-treatment/index.md): Recording a diagnosis and prescribing medication.
- [5. Programs](programs/index.md): Completing program forms for a patient.
- [6. Referral](referral/index.md): Referring a patient and viewing referrals.
- [7. Vaccine](vaccine/index.md): Recording vaccines given to a patient.
- [8. Tests](tests/index.md): Requesting lab tests and viewing request history.
- [9. Program registries](program-registries/index.md): Enrolling patients in program registries.
- [10. History](history/index.md): A patient's visit and vaccine history.
- [11. Reports](reports/index.md): The survey activity summary.
- [12. Sync](sync/index.md): Syncing the device with the central server.
