# Mobile

Guides to using Tamanu on a mobile device.

## Modules

- [Signing in](signing-in/index.md): Signing in, choosing a facility, and signing out.
- [Patients](patients/index.md): Finding patients, registering them, and viewing their details.
- [Vitals](vitals/index.md): Recording and reviewing a patient's observations.
- [Diagnosis and treatment](diagnosis-and-treatment/index.md): Recording a diagnosis and prescribing medication.
- [Programs](programs/index.md): Completing program forms for a patient.
- [Referral](referral/index.md): Referring a patient and viewing referrals.
- [Vaccine](vaccine/index.md): Recording vaccines given to a patient.
- [Tests](tests/index.md): Requesting lab tests and viewing request history.
- [Program registries](program-registries/index.md): Enrolling patients in program registries.
- [History](history/index.md): A patient's visit and vaccine history.
- [Reports](reports/index.md): The survey activity summary.
- [Sync](sync/index.md): Syncing the device with the central server.
