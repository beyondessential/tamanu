Record a patient's ongoing conditions, allergies, family history, other issues and care plans, so
anyone who opens their record can see them. Start from the panel on the left of the patient's record.

**[Screenshot: Roy Antonini's record, with Add beside Ongoing conditions outlined in red]**

# Before you start

The lists to choose from, such as conditions and allergies, are set up by your site. A patient who
has died cannot have their history changed.

# Add an ongoing condition

Record a long-term condition the patient has, such as hypertension.

1. Select **Add** beside **Ongoing conditions**.

   A form opens in the panel.

2. Fill in the form.

   - **Condition name**: start typing the condition, then select it from the list
   - **Date recorded**: today's date is filled in. Change it if the condition was recorded earlier
   - **Clinician**: who recorded the condition
   - **Notes**: anything else worth knowing

3. Select **Add**.

   The condition is listed under **Ongoing conditions**.

   **[Screenshot: the ongoing condition form filled in, with Add outlined in red]**

# Resolve or delete an ongoing condition

Resolve a condition the patient no longer has. Delete a condition only if it was recorded in error.

1. Select the condition under **Ongoing conditions**.

   The condition's form opens.

2. To resolve it, tick **Resolved**, fill in **Date resolved**, **Clinician confirming resolution**
   and **Notes on resolution**, then select **Save**.

   The condition stays in the list, marked **(resolved)**.

   **[Screenshot: a condition being resolved, with Save outlined in red]**

3. To delete it, select **Delete**, then select **Delete** again in the **Delete ongoing condition**
   window.

   The condition is removed and cannot be brought back. Deleting needs permission. Contact your
   system administrator if you believe you should be able to delete conditions.

   **[Screenshot: the Delete ongoing condition window, with Delete outlined in red]**

# Add an allergy

1. Select **Add** beside **Allergies**.

2. Fill in the form.

   - **Allergy name**: start typing the allergy, then select it from the list
   - **Reaction**: the reaction the patient has
   - **Date recorded**: today's date is filled in. Change it if needed
   - **Clinician** and **Notes**

   **[Screenshot: the allergy form filled in for Penicillins, with Add outlined in red]**

3. Select **Add**.

   The allergy is listed under **Allergies**.

## If the allergy is not in the list

If your account can add to your site's lists, an allergy that is not in the list appears as you type
it, marked **(item not in list)**. Selecting it adds the allergy to the list for everyone at your
site, so check every spelling first, and type the name exactly as it should appear. Ask your system
administrator to correct a misspelt allergy, rather than adding it again.

**[Screenshot: Mosquito bite (item not in list) under Allergy name, outlined in red]**

# Add family history

Record a condition that a member of the patient's family has had.

1. Select **Add** beside **Family history**.

2. Fill in the form.

   - **Diagnosis**: start typing the condition, then select it from the list
   - **Date recorded**: today's date is filled in. Change it if needed
   - **Relation to patient**: who in the family had it, such as Mother
   - **Clinician** and **Notes**

   **[Screenshot: the family history form filled in, with Add outlined in red]**

3. Select **Add**.

   The condition is listed under **Family history**, with the relation after it.

# Add another issue or a warning

Record anything else staff should know about the patient. An issue is listed in the panel. A
warning is listed too, and also pops up in a **Patient warnings** window each time anyone opens the
patient's record, so keep warnings to what everyone must see.

1. Select **Add** beside **Other patient issues**.

2. Choose **Issue** or **Warning** under **Type**, and write it under **Notes**.

   **[Screenshot: the other patient issues form with Warning chosen, with Add outlined in red]**

3. Select **Add**.

   From then on, opening the patient's record shows the warning. Select **OK** to close it.

   **[Screenshot: the Patient warnings window, with OK outlined in red]**

# Add a care plan

1. Select **Add** beside **Care plans**.

   The **Add care plan** window opens.

2. Fill in the form.

   - **Care plan**: start typing, then select the plan from the list
   - **Date recorded**: now is filled in. Change it if needed
   - **Clinician**: who recorded the plan
   - **Main care plan**: what the plan is

3. Select **Add**.

   The care plan is listed under **Care plans**.

   **[Screenshot: the Add care plan window filled in, with Add outlined in red]**

# Add a note to a care plan

1. Select the care plan under **Care plans**.

   A window opens, showing the main care plan and every note added to it.

2. Write the note at the top of the window. Choose who you are writing it for under **On behalf
   of** if it isn't you, and change **Date Recorded** if needed.

3. Select **Add note**.

   The note is added below the main care plan. To change or delete a note, select the three dots
   beside it.

   **[Screenshot: the Care plan: Cardiovascular disease window with a note written, with Add note outlined in red]**

# View or change an item

1. Select the item in the panel.

   Its form opens, showing everything recorded about it. A care plan opens in its own window.

   **[Screenshot: the panel listing Roy Antonini's history]**

2. Change what you need, then select **Save**.

   To close the form without changing anything, select **Cancel**.

   **[Screenshot: an issue's form open for editing, with Save outlined in red]**
