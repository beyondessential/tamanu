Print a patient's ID card, ID labels and certificates, or email them their International Patient
Summary. Start from the panel on the left of the patient's record.

# Before you start

Which documents you can choose depends on how your site is set up and on your permissions.

# Print a document

1. Select **Patient resources** at the bottom of the panel.

   The **Patient resources** window opens.

   **[Screenshot: the Patient resources window]**

2. Select the document you want.

   | Document | What it is |
   | --- | --- |
   | **ID card** | An identification card with a barcode. It shows the patient's photo if one has been taken |
   | **Multiple ID labels** | A sheet of identification labels |
   | **QR code ID** | An identification card with a QR code |
   | **Birth notification** | The patient's birth details, and their parents' details if they are linked in Tamanu |
   | **Test certificate - COVID-19** | The patient's COVID-19 test results |
   | **Clearance certificate - COVID-19** | A certificate that the patient is clear of COVID-19 |

   A preview of the document opens.

3. Select **Print**.

   Your browser's print window opens.

   **[Screenshot: the preview of Multiple ID labels, with Print outlined in red]**

   To email the COVID-19 test certificate instead, select **Email**. Enter the address under
   **Patient email** and again under **Confirm patient email**, then select **Confirm**.

4. To close the preview, select the cross at its top right.

# Email an International Patient Summary

An International Patient Summary is a summary of the patient's medical record that they can take
with them when they travel. Tamanu emails the patient a QR code that opens it.

1. Select **Patient resources**, then **International Patient Summary**.

   The **International Patient Summary** window opens, showing the patient's date of birth.

2. Check the date of birth.

   The patient enters it to open their summary, so it must be right. If it is wrong, select
   **Cancel** and correct it on the **Details** tab first. See
   [Edit a patient's details](04-view-and-edit-details.md#edit-a-patients-details).

3. Enter the patient's email address under **Patient email**, and again under **Confirm patient
   email**.

4. Select **Send**.

   **[Screenshot: the International Patient Summary window, with Send outlined in red]**
